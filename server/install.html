Design notes

Point at what looks wrong on a page, write a note, press Submit. Claude Code gets the notes and fixes the code.

  1. Show the bookmarks bar if it is hidden: ⌘ ⇧ B (Ctrl ⇧ B on Windows/Linux).
  2. Drag this button onto the bookmarks bar:
    📏 Design notes
  3. Open your site and click the bookmark. Click it again to turn it off.
On the page
  • space between two blocks · padding inside a block · space between side-by-side items
  • Click a number, or Alt + click anything, and type a note. Enter saves.
  • Submit sends every note to Claude Code (run /design-notes:notes there first). Copy gives you the notes as text instead.
  • Notes are kept in this browser until you submit or clear them.
